# Glossary

| Term | Meaning |
|---|---|
| Classic profile | A packaged profile that describes the style of an author whose works are in the public domain. Its targets were measured on these works. |
| CEFR | Common European Framework of Reference for Languages, with the levels A1 to C2; in German *GER*. |
| Depth of intervention | The extent to which neutralisation rewrites a text: gentle, normal or thorough. |
| Dimension | One aspect of neutralisation, for example tone, register, redundancy or figurative language. |
| Dosage | The description of how visible a feature is at a given strength. |
| Endpoint | The address of the OpenAI-compatible chat-completions service that runs the language model. |
| Guided tab | The tab *My style → skill*, which leads in four steps from an own text sample to a skill. |
| Indicator | A counted feature that belongs to a slider, for example personal pronouns per 100 words. |
| Interface language | The language of labels and messages, English or German. It is taken from the browser and can be changed in Gradio's settings. |
| Metrics | The values measured in the reference texts of a profile. They are kept as a record and are not edited. |
| Neutralisation | The first step of the neutral path. It removes the style of a text along the selected dimensions and keeps its content. |
| Own profile | The profile of the current session. It is created by an analysis, a description, a refinement, a profile code or a profile file. |
| Profile | A complete description of a style: slider values and neutralisation settings, and optionally measured targets, a description, rules and own sliders. |
| Profile code | A single line beginning with `tsp1.` that contains a complete profile. |
| Rule | A short instruction within a profile, derived by the model or written by the user. |
| Side bar | The panel *⚙️ Settings* with profile, neutralisation, sliders and measured targets; it applies in every tab. |
| Skill | A folder with a `SKILL.md` file that gives Claude instructions for a task, here for writing in a style. The application exports it as a ZIP archive. |
| Slider | A setting for one style feature. A slider has two poles (−10 to +10), an intensity (1 to 10) or stages (CEFR level, audience age). |
| Styling | The application of the target style. It is the second step of the neutral path and the only step of the direct path. |
| Target | A measured value that the result is to approach, for example words per sentence. The analysis presets targets; the user can change them. |
| Text language | The language of the text being rewritten, one of English, German, French, Spanish, Italian and Polish. The result is written in this language. |
